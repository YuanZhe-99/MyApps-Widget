# MyApps-Widget

Shared home-screen widget infrastructure for the MyApps family on Android and iOS: a versioned,
tolerant envelope stored per widget kind, a Flutter plugin that publishes it and redraws the native
widgets, a WidgetKit reader, and small Flutter building blocks for settings and previews.
Applications keep their payloads, layouts, views and wording.
